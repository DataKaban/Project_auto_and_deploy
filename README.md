# Автоматизированная система сбора и обработки данных розничной сети

## Описание проекта
Данный проект представляет собой  ETL-конвейер для торговой сети. Система имитирует работу кассового ПО, генерирует ежедневные отчеты о продажах в формате CSV и автоматически загружает их в базу данных PostgreSQL на удаленном сервере Ubuntu.

**Основные возможности:**
* **Эмуляция данных**: Генерация чеков для N магазинов и произвольного количества касс.
* **Автоматизация**: Расписание для генерации и загрузки данных через `cron`.

## Структура проекта
* `bill_generations.py` — Скрипт-генератор продаж (создает файлы в `data/`).
* `loader.py` — Скрипт-загрузчик (читает CSV, записывает в БД, удаляет обработанные файлы).
* `db_client.py` — Модуль для связи с PostgreSQL.
* `config.py` — Логика обработки конфигурации (динамическое определение путей).
* `config.ini` — Файл с настройками (БД, пути, структура сети, продукты, категории продуктов).
* `sql/` — DDL-скрипты для развертывания таблиц базы данных.
* `img/` — Скриншоты работы системы (ER-диаграмма, Cron, БД).
* `data/` — Директория для временного хранения выгрузок.

## Технологический стек
* **Язык**: Python 3.10+
* **Библиотеки**: Pandas, Psycopg2, Configparser
* **База данных**: PostgreSQL 16
* **ОС**: Ubuntu 24.04 (Linux)
* **Инструменты**: Cron, Git, DBeaver

## Инструкция по развертыванию

### 1. Подготовка сервера и окружения
Клонируйте репозиторий и настройте виртуальное окружение:
```python
git clone [https://github.com/DataKaban/Project_auto_and_deploy.git](https://github.com/DataKaban/Project_auto_and_deploy.git)
cd Project_auto_and_deploy
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка базы данных
Для развертывания структуры базы данных необходимо выполнить SQL-скрипт.
Создайте базу данных (например, shops_sim) в PostgreSQL.
Выполните DDL-команды из файла sql/create_tables.sql
Скрипт создаст таблицы в правильном порядке с учетом внешних ключей (FOREIGN KEY)

### 3. Конфигурация системы

Отредактируйте файл config.ini в корне проекта.
    * Укажите параметры подключиния к вашей БД в секции [postgresql] 
    * Укажите название папки куда будут выгружатся CSV-файлы в секции [paths]
    * Укажите данные сети магаизнов и касс в секции [network]
    * Укажите категории товаров в секции [categories]
    * Укажите соответствие товаров и их категорий в секции [items]


### 4. Автоматизация (Cron)
Для автономной работы системы настройте планировщик задач командой crontab -e:
```bash
# Генерация отчетов: Пн-Сб в 09:00
0 09 * * 1-6 cd /home/project_auto && /home/project_auto/venv/bin/python bill_generations.py >> /home/project_auto/gen.log 2>&1

# Загрузка данных в БД: Ежедневно в 13:00
00 10 * * * cd /home/project_auto && /home/project_auto/venv/bin/python loader.py >> /home/project_auto/load.log 2>&1
```
